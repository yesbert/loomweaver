sandboxed · static tab

A static, non-closable tab 📌

This is a second sandboxed plugin. It registered its content route with tab: {…}, so the host shows it in the Dashboard strip from the start — next to Overview | Trends | Export — and it has no close button, exactly like a first-party static tab.

The other frame plugin (the blue one) instead opens as a dynamic, closable tab on demand. Same isolation (its own <iframe sandbox> + Penpal RPC), different tab lifecycle — the plugin chooses by declaring tab (static) or not (dynamic, opened via openContentTab).

It owns everything below its prefix

It also declared rest: true, so every deeper address under sandbox-static belongs to it and arrives here verbatim — query string included. The prefix stays the tab root, so all of this is one tab.
