sandboxed · installed from the store

Installed at runtime 🛍️

This plugin is not composed in the testbed's code. It is listed in the testbed's plugin catalog, and you installed it from Settings → Plugin store: it started the moment you accepted the install dialog, without a reload.

It holds exactly what that dialog listed. It may contribute to the UI, which gives it this page at /store-full and a settings section, and it may show messages, which it uses to answer a settings change with a toast. Revoke either right or uninstall it under Settings, and this page goes, live. It runs in the same <iframe sandbox> behind the same default-deny broker as every sandboxed plugin.
