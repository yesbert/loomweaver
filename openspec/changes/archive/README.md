# Archived changes

Each directory here is the record of one change that has been implemented: why it was proposed, how
it was designed, and the tasks it was carried out in. They are dated records, and they are not
maintained.

**They name things as they were named then.** The npm scope was `@loom` before 2026-08-27. The
assistant context lived at `.claude/` inside this repository before it moved to a private one.
Decisions carried numbers before that corpus was dissolved into the capabilities. A path or a name
in these files that resolves to nothing today is correct as history, and correcting it would only
make the record lie about what was true when it was written.

**Some of them refer to changes that are not here.** Thirty-odd capabilities were specified in a
single automated backfill in August 2026. That output was never reviewed line by line, so it was
kept privately rather than published, and a reference to a `backfill-*` change leads nowhere in this
repository.

What the platform guarantees today is in `openspec/specs/`, verified against the code. Where a file
here disagrees with a capability, the capability is right and this is history.
